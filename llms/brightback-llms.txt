# Brightback (Chargebee Retention)

> Brightback is a churn-prevention / cancellation-experience platform, now part
> of Chargebee as Chargebee Retention. Its pre-cancel API initiates a hosted
> cancel/save session for a churning subscriber and returns a unique Cancel
> Session URL to redirect the end user into a personalized retention flow.

## APIs
- [Pre-cancel API (OpenAPI)](openapi/brightback-retention-openapi.yml): POST /precancel to create a cancel session.
